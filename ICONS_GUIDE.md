# Icon / logo guide
Put PNG files with these exact names. If a file is missing, the built-in icon is shown instead (nothing breaks).

## Install icons (in frontend/ next to index.html)
| File | Size | Notes |
|---|---|---|
| icon-192.png | 192x192 | square, full colour |
| icon-512.png | 512x512 | square, full colour |
| icon-maskable-512.png | 512x512 | keep the logo inside the centre 410x410 circle; fill whole square with background colour |
| apple-touch-icon.png | 180x180 | iPhone/iPad home screen, no transparency |
| favicon.png | 64x64 | browser tab |

## Logo and button images (in frontend/img/)
| File | Where it appears | Size |
|---|---|---|
| logo.png | sidebar brand + About card | 512x512 transparent |
| nav-overview.png, nav-record.png, nav-photos.png, nav-layout.png, nav-settings.png | bottom tab bar / sidebar | 96x96 transparent |
| form-methane.png, form-redox.png, form-height.png, form-panicle.png, form-grains.png, form-straw.png, form-seed.png, form-flower.png | Record data list | 96x96 transparent |
| photo-daily.png, photo-problem.png | Photos menu | 96x96 transparent |
Tip: use one colour that reads on both light and dark mode (mid green/grey). After changing files, reload twice (or clear site data) because the app caches files.
